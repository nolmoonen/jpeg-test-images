# jpeg-test-images

This repository hosts JPEG images and scripts to generate JPEG images to support the development of a JPEG decoder.

- `benchmark` contains a script to compress a standardized set of images with number of popular JPEG encoders, used to check the performance of a JPEG decoder.
- `test` contains many small images to verify a JPEG decoder.
- `unique` hosts a set of JPEG file each created with a different encoder.

All images appearing in this repository should be specification-compliant and may be baseline or extended (includes progressive) JPEGs.
