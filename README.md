# jpeg-test-images

This repository hosts JPEG images and scripts to generate JPEG images to support the development of a JPEG decoder. A few strategies are available:

- `encoder` contains a scripts to compress a standardized set of images with number of popular JPEG encoders.
- `test` contains a script to generate many small images for verification.
- `unique` hosts a set of JPEG file each created with a different encoder.

All images appearing in this repository should be specification-compliant and may be baseline or extended (includes progressive) JPEGs.
